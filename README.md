# Шпаргалка оператора — офлайн-версия

Калькуляторы для площадки, база камер и объективов. После первого открытия работает без интернета.

## Как выложить на GitHub Pages

1. Зайди на github.com → **New repository**. Имя, например, `dp-cheatsheet`. Тип **Public** (на бесплатном аккаунте Pages работает только с публичными репозиториями). Создай репозиторий.
2. На странице репозитория нажми **uploading an existing file** (или **Add file → Upload files**).
3. Перетащи в окно **всё содержимое** этой папки: `index.html`, `sw.js`, `manifest.webmanifest`, три иконки и папку `fonts` целиком. Нажми **Commit changes**.
4. **Settings → Pages**. В блоке *Build and deployment*: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты сайт появится по адресу `https://ТВОЙ-ЛОГИН.github.io/dp-cheatsheet/` (ссылка будет вверху той же страницы Settings → Pages).

## Как поставить на iPhone

1. Открой ссылку в **Safari** при включённом интернете.
2. «Поделиться» → **На экран «Домой»** → Добавить.
3. **Открой приложение с иконки один раз, пока есть интернет**, и подожди пару секунд. Иконка на экране «Домой» хранит свой отдельный кеш, поэтому этот запуск нужен, чтобы файлы сохранились именно для неё.
4. Всё. Дальше работает в авиарежиме.

Другу достаточно отправить ту же ссылку и повторить шаги для iPhone.

## Как обновить

Загрузи новые файлы поверх старых (Add file → Upload files → Commit). В `sw.js` должна смениться строка `const CACHE = 'dp-cheatsheet-…'`; в комплектах, которые собирает Claude, она меняется сама. На телефоне открой приложение с интернетом, закрой и открой ещё раз — подтянется новая версия.
